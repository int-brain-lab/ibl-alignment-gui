# Documentation lookup

The project is documented in Sphinx. Do not guess behavior when documentation is
available.

For behavior questions, check in this order:

1. `docs/source/` — the authored pages (Markdown and reST): tutorials, how-to,
   explanation and reference. Edit documentation here. `docs/source/api/` is
   generated by autosummary; change the docstrings instead.
2. `CHANGELOG.md` — when and why behavior changed.
3. Docstrings in `ibl_alignment_gui/` — the final authority if docs and code disagree.

The published docs are at https://int-brain-lab.github.io/ibl-alignment-gui/ and
reflect `main`, not the current working tree.
