# References

External repositories useful for understanding the data formats and the libraries
this GUI builds on:

- [ONE](https://github.com/int-brain-lab/ONE) — data access and the ALF file format
- [ibllib](https://github.com/int-brain-lab/ibllib) — IBL pipeline, ephys QC
- [ibl-neuropixel](https://github.com/int-brain-lab/ibl-neuropixel) — `spikeglx`
  reader, `ibldsp` destriping and voltage tools
- [iblatlas](https://github.com/int-brain-lab/iblatlas) — Allen atlas and region tools
- [ibleatools](https://github.com/int-brain-lab/ibleatools) — ephys features and
  region prediction models
- [viewephys](https://github.com/int-brain-lab/viewephys) — raw data viewer
- [SpikeInterface](https://github.com/SpikeInterface/spikeinterface) — sorting
  analyzers, recordings, `export_to_ibl_gui`
