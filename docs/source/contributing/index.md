# Contributing

Contributions to the IBL Alignment GUI are welcome, whether that's fixing a bug, adding a feature
or improving these docs. These pages show you how to set up a development environment, run the
checks your changes need to pass, and write documentation that fits with the rest of the site.

{doc}`developer_guide`
: Set up the environment with uv, run the tests and linting, and open a pull request. Also covers
  building the package and how versions are numbered.

{doc}`writing_docs`
: How the documentation is organised, the templates for each kind of page, and how to build it
  locally.
