# How to look at a single cluster

This guide shows you how to check the waveform and firing of one unit, for example to judge whether
a unit at a candidate landmark is real.

## Steps

1. Show an image plot of cluster data, such as a cluster scatter plot ({kbd}`Alt+1` to cycle).
2. Click a cluster. A window opens with its autocorrelogram and template waveform.

   ```{image} ../../_static/how_to/align/cluster.png
   :alt: A cluster scatter plot with the window for cluster 336 open beside it, showing the cluster's autocorrelogram and template waveform
   :align: center
   ```

3. Click more clusters to open more windows.
4. Press {kbd}`M` to minimise or show all the cluster windows, and {kbd}`Alt+X` to close them.
