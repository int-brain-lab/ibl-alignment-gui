# How to check the trajectory in 3D

This guide shows you how to see the probe trajectory and its channels in a 3D brain, for example to
check that a traced track is plausible.

## Steps

1. Open `Plugins → 3D features`.

   ```{image} ../../_static/how_to/align/3d_features.png
   :alt: The 3D features window, showing the probe and the brain regions it passes through, opened from the Plugins menu
   :align: center
   ```

2. The channels along the probe are coloured by the plot in the Probe plots panel. Change that plot
   in the main window and the 3D view follows.
3. Show a cluster plot in the image panel to see the clusters at their locations, and set their size
   with the marker size slider.
4. Use **Show regions** to show the brain regions the probe passes through, and **Show picks** to
   show the traced points.
