# Install

These guides show you how to add the optional packages that some features of the GUI need. The
basic install, described in {doc}`../../installation`, is enough to align your own data. You only
need an extra for:

`ibl`
: Converting kilosort output, and the IBL online mode.

`ephysatlas`
: The channel prediction models. It also installs everything `ibl` does.

What each extra enables is listed in full in {ref}`ref-optional-dependencies`.
