# Keyboard shortcuts

This page lists every keyboard shortcut in the GUI. The same actions are available from the `Fit
Options` and `Display Options` menus and from the buttons below the figures, so the menus can also
be used to look up a shortcut while working.

## Alignment

| Shortcut | Action |
|---|---|
| Double-click | Add a reference line pair, in the Ephys or Histology figure |
| {kbd}`Enter` | Apply the fit |
| {kbd}`Shift+Right` | Move to the next alignment in the fit history |
| {kbd}`Shift+Left` | Move to the previous alignment in the fit history |
| {kbd}`Shift+D` | Remove the reference line under the cursor |
| {kbd}`Shift+H` | Hide or show all reference lines |
| {kbd}`Shift+R` | Reset the alignment to its original state |
| {kbd}`Shift+U` | Upload the alignment |
| {kbd}`Shift+S` | Save the current alignment to file without uploading it |

## Changing the plots

Each plot type cycles forward with {kbd}`Alt` and backward with {kbd}`Shift+Alt`.

| Shortcut | Action |
|---|---|
| {kbd}`Alt+1` / {kbd}`Shift+Alt+1` | Image plots (forward / backward) |
| {kbd}`Alt+2` / {kbd}`Shift+Alt+2` | Line plots (forward / backward) |
| {kbd}`Alt+3` / {kbd}`Shift+Alt+3` | Probe plots (forward / backward) |
| {kbd}`Alt+4` / {kbd}`Shift+Alt+4` | Slice plots (forward / backward) |
| {kbd}`Alt+5` / {kbd}`Shift+Alt+5` | Region plots (forward / backward) |

## Display

| Shortcut | Action |
|---|---|
| {kbd}`Shift+A` | Reset the axes of every figure to their default limits |
| {kbd}`R` | Reset the range of every plot to its default |
| {kbd}`Shift+L` | Hide or show the brain region labels |
| {kbd}`Shift+C` | Hide or show the trajectory and the channels on the slice image |
| {kbd}`T` | Switch between the tabbed and the grid layout |

## Shanks

| Shortcut | Action |
|---|---|
| {kbd}`Right` | Move to the next shank |
| {kbd}`Left` | Move to the previous shank |

## Plugins

| Shortcut | Action |
|---|---|
| {kbd}`M` | Minimise or show the cluster windows |
| {kbd}`Alt+X` | Close the cluster windows |
