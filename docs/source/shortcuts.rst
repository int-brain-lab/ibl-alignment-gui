Keyboard Shortcuts
==================

A summary of every keyboard shortcut in the GUI. The same actions are available from the
``Fit Options`` and ``Display Options`` menu bars, and from the buttons below the figures, so the
menus can be used to look up a shortcut while working.

Alignment
---------

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - Shortcut
     - Action
   * - :kbd:`Enter`
     - Apply the fit
   * - :kbd:`Shift+Right`
     - Move to the next alignment in the fit history
   * - :kbd:`Shift+Left`
     - Move to the previous alignment in the fit history
   * - :kbd:`Shift+D`
     - Remove the reference line the cursor is over
   * - :kbd:`Shift+H`
     - Hide / show all reference lines
   * - :kbd:`Shift+R`
     - Reset the alignment to its original state
   * - :kbd:`Shift+U`
     - Upload the alignment
   * - :kbd:`Shift+S`
     - Save the current alignment to file without uploading it

A reference line pair is added by **double-clicking** in either the Ephys or the Histology figure.

Changing the plots
------------------

Each plot type cycles forward with :kbd:`Alt` and backward with :kbd:`Shift+Alt`.

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - Shortcut
     - Action
   * - :kbd:`Alt+1` / :kbd:`Shift+Alt+1`
     - Image plots (forward / backward)
   * - :kbd:`Alt+2` / :kbd:`Shift+Alt+2`
     - Line plots (forward / backward)
   * - :kbd:`Alt+3` / :kbd:`Shift+Alt+3`
     - Probe plots (forward / backward)
   * - :kbd:`Alt+4` / :kbd:`Shift+Alt+4`
     - Slice plots (forward / backward)
   * - :kbd:`Alt+5` / :kbd:`Shift+Alt+5`
     - Region plots (forward / backward)

Display
-------

.. list-table::
   :widths: 30 70
   :header-rows: 1

   * - Shortcut
     - Action
   * - :kbd:`Shift+A`
     - Reset the axes of every figure to their default limits
   * - :kbd:`R`
     - Reset the range of every plot to its default
   * - :kbd:`Shift+L`
     - Hide / show the brain region labels
   * - :kbd:`Shift+C`
     - Hide / show the trajectory and the channels on the slice image
   * - :kbd:`T`
     - Toggle between the tabbed and the grid layout
