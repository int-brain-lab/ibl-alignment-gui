# Tutorials

New to the alignment GUI? Start here. These tutorials take you through it step by step, telling
you what to click and what you should see, so you can focus on learning how alignment works. We
recommend following them in order, as each one builds on the one before.

{doc}`01_first_alignment`
: Align a single-shank probe from the sample data, from your first reference line to uploading
  the result.

{doc}`02_multi_shank`
: Align a probe with four shanks from the sample data, using each shank to check the others.

{doc}`03_channel_prediction`
: Use the Channel Prediction plugin to predict brain regions from the electrophysiology, and to
  suggest where your reference lines should go.

{doc}`04_preparing_your_data`
: Turn your own SpikeInterface spike sorting, brainreg histology and brainreg-segment probe track
  into a session the GUI can open.

The first three use the IBL sample data, so you don't need any data of your own to start. Once
you're comfortable with the GUI and have a specific task in mind, the {doc}`../how-to/index` will
get you there faster.
